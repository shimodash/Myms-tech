# 🎮 LED反応ゲーム スケッチ README

Arduinoを使ったLED点灯反応ゲームです。LEDが光っている瞬間にDIPスイッチを押すと得点になります。5回連続ヒットでファンファーレが鳴り、サーボモーターが派手に動きます。

---

## 📦 必要なハードウェア

| 部品 | 型番 / 仕様 | 接続ピン |
|------|------------|---------|
| Arduino | Uno / 互換機 | — |
| LED | 任意（抵抗付き推奨） | **Pin 2** |
| DIPスイッチ | 1回路（SPST） | **Pin 4** |
| サーボモーター | Tower Pro **SG90** | **Pin 7** |
| スピーカー / ブザー | 8Ω スピーカーなど | **Pin 8** |

---

## 🔌 回路図（概要）

```
Arduino Pin 2  ──[330Ω]──┤LED├── GND
Arduino Pin 4  ────────── DIPスイッチ ── GND   (内部プルアップ使用)
Arduino Pin 7  ────────── SG90 信号線（黄）
                          SG90 電源（赤） ── 5V
                          SG90 GND（茶）  ── GND
Arduino Pin 8  ────────── スピーカー (+)
GND            ────────── スピーカー (-)
```

> ⚠️ SG90は起動時に電流を多く消費します。Arduinoの5VピンではなくACアダプタなど外部電源からの給電を推奨します。

---

## 🎮 ゲームのルール

```
[消灯] 0.5〜2秒（ランダム）
   │
   ├─ この間にスイッチを押す → ❌ フライング（ミス）
   │
   ↓
[点灯] 0.3〜1秒（ランダム）
   │
   ├─ 点灯中にスイッチを押す → ✅ ヒット！
   │
   └─ 押せなかった          → ❌ ミス
```

| 結果 | サーボ動作 | 音 | 連続カウント |
|------|-----------|-----|-------------|
| ✅ ヒット（1〜4回） | 0°→180°→0° スイング | ドミソ ♪ | +1 |
| 🏆 5回連続ヒット！ | 0°→180°→0° スイング | ファンファーレ 🎺 | 0にリセット |
| ❌ ミス / フライング | 60°↔120° 小刻み震え | ブー（設定で消音可） | 0にリセット |

5回連続ヒット達成後は自動的にリセットされ、再チャレンジできます。

## ⚙️ 設定エリア

スケッチ先頭の **設定エリア** で動作をカスタマイズできます。

```cpp
// ========================================
// ★ 設定エリア
// ========================================
const bool MISS_SOUND_ENABLED = true;  // ミス音: true=あり / false=なし
// ========================================
```

| 定数 | 初期値 | 説明 |
|------|--------|------|
| `MISS_SOUND_ENABLED` | `true` | `false` にするとミス・フライング時の音が消えます |

---

## 🔧 サーボ制御の仕組み（ライブラリなし）

本スケッチは `Servo.h` を使わず、手動でPWMパルスを生成しています。

```
PWMサイクル = 20ms（50Hz）
 ┌──┐
 │  │___________________
 ↑↑↑
 パルス幅で角度を指定

 500µs  → 0度
 1500µs → 90度（中央）
 2500µs → 180度
```

SG90の公称パルス幅は1〜2msですが、実際には **500µs〜2500µs** でフル可動します。本スケッチではこの実測値を使用しています。

## 🚀 インストール手順

1. Arduino IDEを開く
2. `pitches.h` をスケッチと同じフォルダに配置する  
   （`ファイル` → `新しいタブ` → `pitches.h` として保存）
3. スケッチをArduinoに書き込む
4. 回路を接続して電源を入れる

---

## 💡 カスタマイズのヒント

- **難易度を上げる**: `random(300, 1000)` の点灯時間を短くする（例: `random(200, 600)`）
- **難易度を下げる**: 点灯時間を長くする（例: `random(500, 1500)`）
- **連続ヒット数を変える**: `if (hitCount >= 5)` の `5` を好きな数に変更する
- **ピン番号を変える**: 設定エリアの各 `const int` を修正するだけで対応可能
