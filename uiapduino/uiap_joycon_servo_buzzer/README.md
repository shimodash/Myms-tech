# **UIAPduino Joycon & Dual Servo Controller**

UIAPduino（CH32Vマイクロコントローラ向けArduino互換環境）上で動作する、ジョイコンアナログ入力を用いた2軸サーボモーター制御およびカウントダウンブザーシステムです。

## **概要**

アナログジョイコンの傾きに応じて2つのサーボモーター（X軸・Y軸）の位置およびLEDの点滅スピードをスムーズに制御します。また、トリガースイッチが押された際にはサウンドエフェクト付きのカウントダウン処理を行います。

## **特徴**

* **2軸サーボ制御（非ブロッキング処理）**: 20ms周期のタイマー処理とパルス演算により、サーボのなめらかな動き（ローパスフィルタ処理）を実現。  
* **直感的なLED制御**: ジョイコンX軸の倒し具合（デッドゾーンあり）に応じて、LEDの点滅速度が変化（急に倒すほど高速点滅）。  
* **トリガーカウントダウン機能**: スイッチ入力（アクティブLOW）により、ブザーで「3秒カウント（ピ・ピ・ピ）＋ 1秒フィニッシュ音（ピー！）」を再生。  
* **デバッグシリアル出力**: 各軸のRaw値、サーボ推定角度、トリガー状態を115200bpsでリアルタイム出力。

## **接続構成 (Pinout)**

| 機能 / デバイス | ピン名称 | ピン番号 | 備考 / 可動域 |
| :---- | :---- | :---- | :---- |
| **ジョイコン X軸** | A0 | アナログ入力 | LED点滅速度 / サーボX軸連動 |
| **ジョイコン Y軸** | A1 | アナログ入力 | ブザーピッチ / サーボY軸連動 |
| **トリガースイッチ** | TRIGGER\_PIN | デジタル 7 | 内部プルアップ（H→Lで起動） |
| **サーボモーター X軸** | SERVO\_X\_PIN | デジタル 8 | 90° ± 45° (45° 〜 135°) |
| **サーボモーター Y軸** | SERVO\_Y\_PIN | デジタル 9 | 90° ± 45° (45° 〜 135°) |
| **圧電ブザー** | BUZZER\_PIN | デジタル 10 | カウントダウン音 / トーン出力 |
| **コントロールLED** | LED\_PIN | PD4 | UIAPduinoオンボード制御 |

## **動作仕様**

### **1\. サーボ制御**

* **X軸 (Pin 8\)**: 975us 〜 1925us パルス幅（約45° 〜 135°）  
* **Y軸 (Pin 9\)**: 975us 〜 1925us パルス幅（約45° 〜 135°）  
* アナログ値の変化に対して整数演算による移動平均フィルタを掛け、ハンチングを抑えたスムーズな挙動にします。

### **2\. インジケーターLED (PD4)**

* ジョイコンX軸がセンターデッドゾーン (±60) を超えて傾けられると点滅を開始。  
* 傾きが大きいほど点滅周期が短縮されます (500ms 〜 30ms)。

### **3\. カウントダウン再生**

* Pin 7 が LOW（ボタン押し込み）になるとカウントダウンモードが開始されます。  
* 0〜3秒: 1秒周期で短音（880Hz / 150ms）を鳴らす。  
* 3〜4秒: 完了長音（1760Hz / 1000ms）を鳴らす。

## **開発環境**

* **ボード**: UIAPduino（CH32V003 / CH32V20x 関連ボード）  
* **環境**: Arduino IDE (WCH CH32 Arduino Core 等のUIAPduinoサポートパッケージをインストール済みであること)  
* **シリアル通信**: 115200 bps
