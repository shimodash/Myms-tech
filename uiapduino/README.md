# uiapduino

このフォルダは、Arduino互換ボードの「uiapduino」向けのスケッチを格納しています。

## 概要

`uiapduino` は、uiapduinoマイコン制御用のサンプルスケッチです。
シリアルや入出力ピンを使った簡単な制御・テスト用途を想定しています。リポジトリ内のソースは主にArduinoのスケッチで書かれています。

## 必要環境

- Arduino IDE または PlatformIO
- Arduino 互換ボード（UIAPduino）
- 必要に応じて追加ライブラリ（スケッチ内の include を確認してください）

## インストール・ビルド方法

1. このフォルダ全体を Arduino のスケッチフォルダへコピーするか、Arduino IDE で `uiapduino.ino`（または対応するスケッチファイル）を開きます。
2. ツール -> ボード から使用するボードを選択します。
3. シリアルポートを選択して、アップロードを実行します。

PlatformIO を使う場合は、プロジェクトルートに `platformio.ini` を配置してビルド/アップロードしてください。

## フォルダ構成

- `uiapduino/` - 本スケッチフォルダ（この README を含む）
- ソースファイル（.ino / .cpp / .h） - 実際のスケッチ実装

（必要に応じて、実際のソースファイル名やライブラリ依存をここに追記してください）

## 使用上の注意

- 実機に接続して動作させる際は、電源や配線に注意してください。短絡や過電流によりボードを破損する恐れがあります。
- センサや外部回路を接続する場合は、データシートに従った配線・電圧で行ってください。
